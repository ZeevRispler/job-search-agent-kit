# Setup Job Search

Read AGENTS.md and the existing canonical records. Check file access and available connectors before promising actions. Ask a compact initial batch about target work, location, constraints, CV source, existing applications, storage and external action boundaries. Accept unknowns and do not import preferences from examples.

For local storage, use the generated Markdown workspace. For Obsidian, ask the user to install it and open this folder as a vault. For Notion or another store, map the documented schema and verify write/read access before declaring setup complete. Follow the kit's storage guide if available. Keep one canonical store and record its identity in the canonical-storage section of INSTRUCTIONS.md.

Persist user decisions in INSTRUCTIONS.md, career facts/CV claims separately in profile/CANDIDATE.md, missing facts in the open-questions section of profile/CANDIDATE.md and current state in CONTEXT.md. Establish resume source without changing originals. Default to shortlist and review, while distinguishing defaults from confirmed choices. Finish with working navigation, a validation pass where supported, and one next action.

## Periodic review


Read canonical status, due dates, company recheck triggers and practice review dates. Check unresolved ownership, stale live-role claims, materials awaiting review and upcoming interviews. Use scripts/review.py if the kit is available, otherwise inspect the ledgers directly.

Propose three concrete next actions with evidence and dependencies. Explain coverage limits. Avoid resurfacing deferred roles or rechecking companies without a trigger. Practice selection should balance due weak areas and unseen topics. Record decisions only after the user makes them.

Refresh the dashboard and handoff in CONTEXT.md with artifact paths and open questions. Archive old handoff detail when necessary without losing evidence. Schedule future runs only when requested, with bounded scope and meaningful-change notifications. Never auto-send follow-ups or apply as part of a review.
