# Working on the kit

This repository is a reusable template product. Do not put candidate data, employer histories, real applications, recruiter messages, CVs, credentials, or private interview answers here. Use a separate workspace created by `scripts/init_workspace.py`.

Preserve generic behavior across occupations and storage providers. Read affected documentation and scripts before editing. Run the test suite for script changes. Keep `workspace-template/`, skill paths, and setup prompts consistent. Do not imply optional connectors are installed or that described automations are implemented.

When acting inside a generated workspace, follow that workspace's AGENTS.md and current user instructions instead. The kit does not authorize external actions.
