## Decisions and superseded instructions

Record date, exact decision, source and what it supersedes. Do not turn an agent suggestion into a user instruction. Preserve an unresolved preference as unresolved.

## Canonical storage

Initial default: local Markdown in this workspace. Optional UI: Obsidian. SQLite is a derived index only. No cloud connections or backups are configured. If migrating, record the chosen canonical store, database/page IDs, access limits and migration date here. Local exports then become dated snapshots.
